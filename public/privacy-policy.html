Privacy Policy

Application: CubedPDF (com.aistudio.pdftools.xqmztb) • Effective Date: November 25, 2026

Your PDF documents stay on your device. All 24 PDF editing, merging, splitting, compression, signing, AES-256-GCM password protection, rotation, and ML Kit OCR text extraction tools run 100% locally on your Android device. CubedPDF never uploads your PDF files or images to external servers.

This Privacy Policy explains how CubedPDF ("we", "our", or "the App") handles information when you use our Android application. By using CubedPDF, you agree to the practices described below.

1. On-Device Document Processing & Zero Broad Storage Permissions

  • Local Processing Only: Every PDF operation—including Merge, Split, Compress, Edit, Sign, Protect/Unlock, Rotate, Rearrange, Redact, Watermark, Page Numbers, Compare, Overlay, Images to PDF, PDF to Images, Create PDF, Webpage to PDF, and On-Device ML Kit OCR—executes directly on your device.
  • No Document Uploads: Your PDF documents, signatures, annotations, extracted text, and encryption passwords are never transmitted to or stored on our servers.
  • Zero Broad Storage Permissions: CubedPDF does not request broad storage permissions (such as READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE, READ_MEDIA_IMAGES, or MANAGE_EXTERNAL_STORAGE). The App uses Android's built-in Storage Access Framework (SAF) and Android Photo Picker so it can only access files you explicitly choose.

2. Information We Collect

You can use CubedPDF completely offline in Guest Mode without creating an account. If you optionally sign in, we collect only the minimum information required to provide cloud profile preferences and recent-file metadata sync:

Data Category Details Collected Purpose Optional / Required
Account Info Display name (first & last name), email address, authentication provider ID (Google Sign-In or Email/Password), and workspace role preference. Account authentication, profile display, and syncing user preferences across devices via Firebase Authentication & Cloud Firestore. Optional (Guest Mode requires no account)
Cloud History Metadata Document file name, last tool used, page count, file size, and timestamp (never the PDF file contents). Optional cross-device recent-file history stored in your private Firestore subcollection (users/{uid}/recent_docs). Optional (only when signed in & synced)
Local Recent Files Stored strictly on your device in a local Room SQLite database. Quick access to recently edited documents on your device. Excluded from Android Auto Backup. Device-local only
Privacy-First App Analytics Aggregate, non-personal feature usage events (such as which PDF tool was opened and whether an operation succeeded) via Google Analytics for Firebase. Understanding app reliability and improving PDF tools. Never includes file contents, passwords, or email addresses. Aggregate diagnostics only

3. Advertising ID & Third-Party Tracking

  • No Ads & No Ad Tracking: CubedPDF does not display third-party advertisements and does not sell or share your personal data with data brokers.
  • Advertising ID Disabled: The Android Advertising ID permission (com.google.android.gms.permission.AD_ID) and Ad Services permissions are explicitly removed from the application manifest, and Firebase Analytics ad personalization signals are disabled.

4. Data Security & Encryption

  • Encryption in Transit: All network connections (Firebase Authentication, Cloud Firestore, and optional HTTPS webpage snapshots) use HTTPS/TLS. Cleartext HTTP traffic is disabled app-wide.
  • Local Encryption: Password-protected PDF vaults created with CubedPDF use standard AES-256-GCM encryption with PBKDF2-HMAC-SHA256 key derivation and random salts/IVs. Passwords are never logged or stored in Firestore.
  • Zero-Trust Access Control: Cloud Firestore security rules enforce strict owner-only isolation (request.auth.uid == userId) so no other user can read or modify your synced profile or metadata.

5. Data Retention & Account Deletion

We retain your optional Firebase Authentication account and Cloud Firestore records only while your account remains active. You have full control to delete your account and all cloud data at any time:

  • Instant In-App Deletion: Open CubedPDF → tap your Profile button → tap Delete Account & Cloud Data → confirm (and re-verify your identity if prompted). Your Cloud Firestore profile, synced document history, and Firebase Authentication account are deleted immediately.
  • Web Deletion Request: If you have uninstalled the app, you may submit a deletion request anytime via our public Account & Data Deletion page.

6. Third-Party Service Providers

CubedPDF uses the following Google services strictly for optional sign-in, private cloud sync, on-device OCR, and aggregate diagnostics:

  • Firebase Authentication & Cloud Firestore (Google LLC) — optional user sign-in and private profile/metadata sync.
  • Google Analytics for Firebase (Google LLC) — aggregate feature usage with Advertising ID collection disabled.
  • Google ML Kit Text Recognition (Google LLC) — on-device optical character recognition (OCR) for scanned PDFs and images.

Learn more in Google's Privacy Policy: https://policies.google.com/privacy.

7. Children's Privacy

CubedPDF is a general-purpose document utility and is not directed to children under the age of 13 (or the minimum digital consent age in your jurisdiction). We do not knowingly collect personal information from children. If you believe a child has provided personal information via an optional account, please contact us immediately so we can delete it.

We may update this Privacy Policy periodically to reflect improvements to CubedPDF or legal requirements. Updates will be posted on this page with an updated effective date.
